# 机械臂视觉分拣

基于 STM32、OpenMV 和总线舵机的机械臂视觉分拣项目。本仓库集中整理 v1.5 固件源码、已隐藏联系电话的赛事技术文档及机械臂结构拓扑优化 STEP 模型。

技术文档对应“全球校园人工智能算法精英大赛·算法应用赛”的巧夺天工赛项，队伍编号为 `AIC-2025-98061736`。

## 系统组成

OpenMV 提供视觉检测数据，STM32 通过串口接收数据、选择抓取和放置动作，再向总线舵机发送位置与运动时间指令。机械结构与轻量化设计见技术文档和 STEP 模型。

```mermaid
flowchart LR
    A[OpenMV 视觉模块] -->|USART3 接收检测数据| B[STM32F103RC]
    B -->|USART2 发送位置与时间指令| C[总线舵机]
    C --> D[机械臂与夹爪]
```

当前固件的动作入口位于 `Core/Src/main.c`，包含抓取动作、按检测结果选择放置位置及三轮执行流程。舵机位置、动作时间和颜色映射沿用原始程序，复现时需结合实际装配核对。

## 开发环境

以下配置来自随附的 Keil 工程：

| 项目 | 配置 |
| --- | --- |
| 目标芯片 | STM32F103RC，CubeMX 型号 STM32F103RCT6 |
| IDE | Keil MDK / µVision |
| 编译器 | ARM Compiler 5，原工程记录为 V5.06 update 5 |
| 器件支持包 | Keil.STM32F1xx_DFP 2.2.0 |
| 工程文件 | `firmware/MDK-ARM/4.3.2.uvprojx` |
| 构建目标 | `4.3.2` |
| 配置工具 | STM32CubeMX，可打开 `firmware/4.3.2.ioc` |

1. 安装 Keil MDK、ARM Compiler 5 和对应的 STM32F1 器件支持包。
2. 打开 `firmware/MDK-ARM/4.3.2.uvprojx`，选择 `4.3.2` 目标。
3. 在 Keil 中执行 Build，检查编译结果；输出目录为 `firmware/MDK-ARM/4.3.2/`。
4. 按实际硬件配置调试器、舵机 ID、机械零位和动作参数，再进行下载与设备联调。

仓库中的 OpenMV 相关源码为 STM32 接收端；原始压缩包未提供独立的 OpenMV 摄像头端脚本。硬件运行还需准备与接收协议匹配的视觉端程序。

## 串口连接

以下引脚及波特率取自 `Core/Src/usart.c`，功能取自对应驱动：

| 串口 | TX | RX | 波特率 | 用途 |
| --- | --- | --- | --- | --- |
| USART2 | PA2 | PA3 | 115200 | 总线舵机指令发送 |
| USART3 | PB10 | PB11 | 115200 | OpenMV 数据接收，配合 DMA 与空闲中断 |
| USART1 | PA9 | PA10 | 115200 | 原工程保留串口 |
| UART4 | PC10 | PC11 | 115200 | 原工程保留串口 |

OpenMV 接收端使用 18 字节帧，帧头为 `0xA5`、帧尾为 `0x5A`，中间 16 字节复制到 `Openmv` 结构体。视觉端发送格式应与 `Bsp/openmv.h` 中的结构定义保持一致。
